# clips-expert-systems
Практичні роботи в середовищі CLIPS з дисципліни «Інтелектуальні інформаційні технології»

## Автор
- Студент: Федоренко Роман
- Група: ІН-33-4

## Структура репозиторію
- `Lab1/` – робота з фактами (assert, retract, facts, reset), deffacts, перше правило defrule, шаблон person;
- `Lab2/` – шаблони deftemplate: родинні зв'язки та користувачі системи;
- `Lab3/` – правила defrule: виведення родинної інформації та експертна система «Зорі»;
- `Lab4/` – функції deffunction: система «Зорі» з інтерактивним введенням і перевіркою даних;
- `Lab5/` – префіксні вирази та система контролю датчиків із попередженням;
- `README.md` – опис проєкту.

## Висновки
У ході виконання лабораторної роботи було проведено ознайомлення з системою контролю версій Git та сервісом GitHub і застосовано їх для збереження результатів розробки експертних систем у середовищі CLIPS. Створено публічний репозиторій clips-expert-systems, сформовано структуру з окремими папками Lab1–Lab5 та завантажено файли з фактами, шаблонами, правилами й функціями, розробленими під час виконання перших п'яти лабораторних робіт.

Опановано основні поняття та операції: репозиторій, коміт з описом змін, створення папок через вебінтерфейс, завантаження файлів та оформлення README.md мовою Markdown. 

Збереження проєкту на GitHub забезпечило резервну копію роботи, історію змін і зручний доступ для перевірки за одним посиланням. Структура репозиторію наочно демонструє розвиток експертних систем від простих фактів і шаблонів до правил, функцій та перевірки вхідних даних.
