# Лабораторна робота 5
Префіксні вирази та логічне виведення.

- **Завдання 1:** інфіксні вирази переведено в префіксну форму CLIPS, наприклад `(+ (* (+ 3 4) (+ 5 6)) 7)`.
- **Завдання 2:** система контролю 10 датчиків. Шаблон `sensor` (id, status ok/faulty), правило виводить попередження, якщо 3 або більше датчиків несправні. Перевірено на датчиках (3, 5), (2, 8, 9) та (1, 3, 5, 10).
- **Повторний вивід попередження:** щоб воно не друкувалося кілька разів, використано допоміжний факт-прапорець `warning-given`. Правило спрацьовує лише тоді, коли цього факту ще немає (`not`), і додає його при першому спрацюванні.
