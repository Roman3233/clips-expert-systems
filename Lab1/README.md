# Лабораторна робота 1
Операції з фактами в CLIPS.

- **Завдання 1:** ручне введення фактів `(Today is Thursday)` і `(Tomorrow is Friday)` та робота з базою фактів командами `assert`, `retract`, `facts`, `reset`.
- **Завдання 2:** формування бази фактів із файлу та через `deffacts` (список `what-day-is-it?`), команди `clear` і `watch`.
- **Завдання 3:** просте правило `defrule`, яке знаходить день тижня у фактах і виводить його через `printout`.
- **Завдання 4:** шаблон `deftemplate person` (ім'я, вік, стать) і список `deffacts people` із трьома особами.
