# Лабораторна робота 3
Формування бази правил (`defrule`).

- **Завдання 1:** родинна інформація виводиться виключно правилами. Порядок рівно з 9 рядків забезпечено через `salience`.
- **Завдання 2:** експертна система «Зорі». Вхід: два факти зі спектральним класом і величиною. Вихід: зорі заданого класу, зорі заданої величини, зорі, що відповідають обом умовам, із відстанню в світлових роках.
