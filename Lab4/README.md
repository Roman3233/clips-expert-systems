# Лабораторна робота 4
Створення та використання функцій (`deffunction`).

Експертну систему «Зорі» з ЛР №3 переписано з використанням функцій.

- Дані користувач вводить сам у консолі CLIPS (`ask-class`, `ask-magnitude`).
- Введення перевіряється на коректність: клас має бути O, B, A, F, G, K або M, величина має бути цілим числом від -7 до 15. При помилці система питає ще раз.
- Вивід реалізовано функціями `print-by-class`, `print-by-magnitude`, `print-by-both`.
- Запуск: `(run-stars-es)`.
